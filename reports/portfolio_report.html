Credit risk portfolio report

Report period 2026-11 (the run period, not a data month). Public LendingClub loans, matured vintages. Independent educational project, not a bank system.

Major portfolio changes

  • The 36-month default rate rose 1.16 points from the 2014 vintage (13.73%) to the 2015 vintage (14.89%).
  • Grade D-G loans fell to 15.5% of 2015 volume (2014 was 18.3%), so grade mix alone would have lowered the rate by 0.67 points.
  • Within-grade default rates added 1.84 points. That is the part of the increase mix does not explain.

Concerning trends

  • The model under-predicted the 2015 vintage: mean score 12.01% against 14.89% observed. It ranks loans more usefully than it estimates their level.
  • Interest rates shifted: the int_rate PSI reached 0.235 in 2015-Q4 (mean 10.96 vs 12.47 in 2014), so interest rates fell while outcomes worsened.
  • 7 real alerts fired across the four 2015 quarters, for default-rate deviation and calibration.

Actionable insights

  • Add the layered segment (FICO under 680, DTI 20+, utilization 60%+) to the monitoring pack as a watchlist indicator. It was 8.5% of 2015 loans, with a 22.8% default rate against 14.2% for all other loans.
  • Review the model with its owner and test recalibration on recent vintages before using its scores as probability estimates.
  • Ask why within-grade default rates rose while interest rates fell. Grade alone did not capture it, so track default rates within grade and not only the grade mix.
